# VGTA empirical datasets

The canonical small pilot dataset is generated by
`src/vgta_eval/scenario_generator.py` and materialized under
`experiments/datasets/v0.3-small/` by `make empirical-small`.

The split-remediated harness dataset is materialized under
`experiments/datasets/v0.4-structure-heldout/` by `make remediated-dataset`.
It is evaluated by the `hv-v0.5.1` protocol, retaining the unchanged metric
suite and experiment gates while independently varying
surface lexicons, template namespaces, and topology compositions across the
training and sealed splits. Its manifest records the remediation controls.

The four files are `train.jsonl`, `validation.jsonl`,
`development-test.jsonl`, and `sealed-test.jsonl`. Each row includes split,
generator, ontology, normative-profile, topology-hash, and synthetic-data
provenance. The sealed split is never used by the training function.

The empirical data directories under `data/` contain provenance/readme
boundaries for the existing canonical ontology fixtures. The canonical
axiology remains [the governed ontology fixture](../../ontology/axiology/core-axiology.ttl)
to avoid maintaining duplicate value graphs.
