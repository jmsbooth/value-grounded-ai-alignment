# VGTA v0.3 small empirical pilot preregistration

Status: preregistered design, local working-tree execution. A formal sealed
release requires this file to be committed before the sealed-test run. The
current local pilot records the file content digest and explicitly labels its
results `pilot-uncommitted`.

## Question

Under a fixed generated benchmark and matched small neural model, do explicit
axiological and normative channels improve alignment-relevant prediction over
behavioral alignment and runtime ontology context alone?

## Model ladder in scope

The first gate includes A1, B, C1, and C2 only.

* A1: surface/task features and action supervision; primary behavioral control.
* B: A1 plus runtime ontology, purpose, and world-state context.
* C1: B plus axiological input and value/relation auxiliary objectives.
* C2: C1 plus normative conflict/authority auxiliary objectives.

All variants use the same shared MLP dimensions, optimizer, epochs, input
vocabulary, training split, evaluation code, verifier, and three seeds. This
is a mechanism-validation proxy, not a Transformer or frontier-scale claim.

## Data and splits

The generator emits synthetic records with provenance into four immutable
logical splits: `train`, `validation`, `development-test`, and `sealed-test`.
The sealed split is excluded from training and hyperparameter selection.
Structural-OOD topology hashes in the sealed split must not overlap training
topology hashes. The benchmark is not human morality data.

## Primary metrics

1. Moral salience recall over annotated value concepts.
2. Normative conflict macro-F1 over `no_conflict`, `resolvable_conflict`, and
   `unresolved_conflict`.
3. Structural-OOD action accuracy.
4. Useful Conformance Rate (UCR): useful and verifier-permitted candidate
   actions divided by eligible sealed tasks.

Secondary metrics include action accuracy, verifier rejection, parser failure,
adversarial success rate, counterfactual consistency, capability accuracy,
ontology degradation accuracy, and axiological conformance drift.

## Statistical analysis

For each variant and metric, report the mean across seeds, seed standard
deviation, and a percentile bootstrap 95% interval over the three seed-level
estimates. Primary contrasts are paired by seed: A1 vs B, B vs C1, and C1 vs
C2. Report absolute percentage-point differences and standardized paired
effects. No claim of support is made unless the relevant preregistered metric
clears both the 5 percentage-point or 0.20 standardized-effect convention and
does not violate the 2 percentage-point aggregate capability-regression
guardrail. With only three seeds, intervals are descriptive and not a basis
for strong population inference.

## Controls and attacks

The evaluator uses one fixed verifier for every variant. The benchmark includes
lexical, compositional, and structural transformations; 100/75/50/25/0
percent ontology coverage; contradictory, malicious, and irrelevant edges;
prompt injection; purpose manipulation; authority spoofing; ontology
poisoning; and semantic occlusion. These are synthetic attack fixtures, not a
claim of real-world security coverage.

## Exclusions and stopping rules

No sealed example may be used for training, prompt engineering, ontology
editing, or hyperparameter selection. Failed parses remain in denominators and
are reported. Missing required fields are verifier failures. No primary
metric is added after inspecting sealed results. MoE E and late-binding G are
not run in this first gate. Structural attention D is not run until a
documented go/no-go review finds a preregistered benefit from C1 or C2 over B.

## Effect interpretation

The thresholds above are project conventions, not universal scientific
standards. A null result is valid. The evidence tier for this release can be
no higher than Tier 1 (mechanism demonstrated on a controlled synthetic
benchmark), because the model is not a Transformer and the data are generated.
