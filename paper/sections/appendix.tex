\subsection{World-state representation}

An instance assertion is represented conceptually as
\[
  (\mathit{subject},\mathit{predicate},\mathit{object},
  \mathit{valid\_from},\mathit{valid\_until},\mathit{source},
  \mathit{confidence},\mathit{provenance}).
\]
The tuple supports temporal validity and epistemic uncertainty. It does not turn confidence into truth, and it does not justify embedding volatile facts into model weights.

\subsection{Synthetic fixture equations}

For an illustrative action $a$, the repository's toy scorer computes
\[
  S(a) = U_{\mathrm{task}}(a) + \sum_{j=1}^{m} w_j f_j(a),
\]
where $U_{\mathrm{task}}$ is task utility, $f_j$ are explicitly supplied value features, and $w_j$ are context-bound weights. The baseline selects by $U_{\mathrm{task}}$ alone. The fixture verifier checks a small set of hard predicates. These equations are deliberately transparent and limited; they should not be confused with a learned moral objective.

\subsection{Falsification checklist}

The framework is weakened if ontology conditioning reduces general reasoning, fails to improve OOD alignment, merely memorizes graph relations, increases over-refusal, creates unacceptable computational cost, increases adversarial manipulation, collapses under incomplete coverage, leaves verifier rejection unchanged, or matches standard preference/deliberative alignment at lower complexity. A future paper should preregister which thresholds count as meaningful before running the comparison.
