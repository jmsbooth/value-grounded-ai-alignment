\section{Experimental Method}
\label{sec:method}

\subsection{Experimental Question}

The first gate tests whether explicit axiological and normative channels improve alignment-relevant prediction over a behavioral control and runtime ontology context alone. The estimand is a difference in held-out task metrics between adjacent model variants under matched input features, allocated parameters, training data, optimizer, inference code, verifier, and seeds. The pilot design was specified before execution but was not committed before the sealed run; it is therefore treated as a mechanism-validation pilot rather than a formally preregistered confirmatory experiment.

\subsection{Pilot Architecture}

The executed pilot is a shared NumPy multilayer perceptron with one hidden layer and task-specific action, value, relation, conflict, purpose, and capability heads. The model receives feature groups corresponding to surface context, domain ontology, axiological structure, normative context, purpose, world state, and capability. Model variants mask or train these groups according to the ladder below. All variants use the same allocated parameter count; the verifier is applied after candidate-action formation and is not a model variant.

\subsection{Dataset and Splits}

The benchmark generator emits synthetic records with feature groups, labels, topology hashes, and provenance. Four logical splits are materialized: training, validation, development-test, and sealed-test. The trainer consumes only the training split; validation and development-test support development checks; the sealed-test split is held out from training, prompt construction, ontology editing, and hyperparameter selection. Structural-OOD records use held-out topology hashes, and the runner fails if a sealed structural topology overlaps training. The benchmark represents a controlled scenario grammar rather than human moral judgments.

The sealed split includes moral-salience, normative-conflict, purpose-relevance, structural-OOD, adversarial, ontology-degradation, and capability families. Ontology coverage is reduced to 100, 75, 50, 25, and 0 percent, with contradictory, malicious, and irrelevant transformations. Candidate actions are normalized against one fixed schema so that parser failure, rejection, and wrong-but-well-formed actions remain distinguishable.

\subsection{Training}

Each variant is trained from a fresh seeded initialization with the same hidden dimension, epoch count, learning rate, L2 penalty, training records, and optimizer. The auxiliary objectives are the only planned training differences. The proxy uses CPU-only NumPy computation. Per-run manifests record the model variant, seed, parameter count, hyperparameters, dataset hash, configuration hash, ontology and verifier versions, elapsed time, and approximate training and inference FLOPs.

\subsection{Metrics}

Primary metrics are moral-salience recall, normative-conflict macro-F1, structural-OOD action accuracy, and Useful Conformance Rate (UCR). Secondary metrics include action and purpose accuracy, capability accuracy, counterfactual consistency, ontology-degradation accuracy, verifier rejection, parser failure, mean action confidence, false-confidence rate, and synthetic attack success. UCR is useful and verifier-permitted candidates divided by eligible tasks. Capability, rejection, unsafe acceptance, over-refusal, bypass, and action semantic completeness are reported alongside it.

\subsection{Security Tests}

The attack fixture includes prompt injection, purpose manipulation, authority spoofing, ontology poisoning, semantic occlusion, and additional structured perturbations. Attack success is measured on the sealed split with the same candidate schema and verifier for every variant. These fixtures test the implementation's attack pathways; they do not estimate real-world security.

\subsection{Statistical Analysis}

For each variant and metric, the analysis reports the mean across three seeds, seed standard deviation, and a percentile bootstrap 95 percent interval over seed-level estimates. Adjacent contrasts are paired by seed: A1 versus B, B versus C1, and C1 versus C2. Absolute percentage-point differences are primary; standardized paired effects are supplementary and are reported as `NA (zero paired variance)' when undefined. A criterion is marked met only when the direction-specific interval clears the predefined absolute threshold and the standardized effect is defined and clears its threshold. With three seeds, intervals are descriptive rather than population estimates. Hypotheses H7 and H8 are exploratory because the current pilot does not implement the required continual-learning or full conformance protocol.

\subsection{Reproducibility}

The runner writes a unique raw directory containing one manifest and prediction file per variant-seed pair. The analyzer reads only those raw files and emits CSV tables, JSON statistics, Markdown result facts, vector figures, and LaTeX fragments. The generated reproducibility record reports the repository commit, run identifier, dataset generator version, configuration hash, ontology version, prediction count, seeds, structural-OOD leakage audit, verifier version, hardware, and approximate FLOPs.
