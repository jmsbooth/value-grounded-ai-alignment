\section{Evaluation framework}
\label{sec:evaluation}

The first paper defines an evaluation architecture rather than reporting experiments. The minimum comparison is a matched ladder of models A--F, with an optional G for governed dynamic normative binding. Each model should use the same base architecture, parameter budget, training tokens, inference budget, prompts, context allocation, and temperature. Datasets, seeds, and evaluation scripts must be versioned before results are interpreted.

\subsection{Models and controls}

Model A is a baseline Transformer. Model B adds external ontology context without structural conditioning. Model C adds axiological and normative auxiliary objectives. Model D adds ontology-conditioned attention. Model E adds ontology-conditioned, reasoning-function MoE routing. Model F adds independent formal action verification. Model G adds a governed dynamic normative ontology if the data and authority protocol are mature enough. The key controls are parameter count, training compute, inference FLOPs, context length, and refusal opportunity.

\subsection{Metrics}

Measure standard task capability, alignment benchmark performance, normative reasoning accuracy, moral-salience recall, contradiction rate, ontology violation rate, jailbreak success, over-refusal, under-refusal, OOD generalization, counterfactual consistency, verifier rejection, attention entropy, expert-routing entropy, inference FLOPs, latency, training efficiency, and robustness to ontology noise. Report effect sizes, confidence intervals, multiple seeds, and per-scenario failures. Do not reduce the result to a single alignment score.

For binary outcomes, a proportion and interval are appropriate descriptive summaries. For paired model comparisons, use paired bootstrap or a preregistered randomization test and report the estimand. For continuous metrics, report mean or median with uncertainty, distributional plots, and compute-normalized comparisons. If human judgments are used, preserve disagreement rather than collapsing it prematurely; recent value-alignment work demonstrates why population and linguistic variation matter \citep{sorensen2024pluralistic,xu2024multilingualvalues,yao2024fulcra}.

\subsection{Synthetic executable scaffold}

The repository includes four constructed scenarios that exercise consent and privacy, workplace coercion, safety checks, and medical-record disclosure. A task-utility baseline and a transparent value-feature scorer choose among two candidate actions; a toy verifier checks authorization, consent, coercion, and a harm threshold. Bootstrap intervals are computed with a fixed seed. The output is explicitly labeled synthetic and is included to validate interfaces and demonstrate different use cases, not to estimate model performance or support an alignment claim.
