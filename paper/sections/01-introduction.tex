\section{Introduction}
\label{sec:introduction}

Language-model alignment is commonly studied as a behavioral problem: training and evaluation move a model toward useful instruction following, preference satisfaction, or compliance with a written policy. That framing has produced effective methods, but it leaves open a narrower systems question. A model may satisfy a local behavioral target while losing track of which entities are affected, which values are at stake, which norms apply, what purpose governs the task, or whether current world-state assertions are reliable.

This paper asks whether those distinctions can become explicit computational inputs. The research question is:

\begin{quote}
Can a governed external canonical axiology be compiled into a derived neural module and used as structural conditioning, while contextual norms are late-bound, purpose selects domain relevance, world state remains evidence-bearing, and consequential candidate actions are independently checked?
\end{quote}

The proposed answer is Value-Grounded AI Alignment (VGA), instantiated by the reference Value-Grounded Transformer Architecture (VGTA). VGA separates a canonical axiology $O_A^v$, normative assertions $O_N$, a domain ontology $O_D$, a purpose model $P$, and a time-indexed world state $W_t$. A compiler derives the non-authoritative module $A_\phi^v=C_\phi(O_A^v)$. Neural interventions may use that module for representation, attention, routing, or semantic state; normative authority and current evidence remain explicit context; and an independent verifier evaluates structured candidate actions before external effects.

The paper develops the model, places it among alignment, neuro-symbolic, knowledge-enhanced, and formal-methods research, and evaluates an initial mechanism-validation implementation. The implementation is a deterministic synthetic benchmark paired with a shared NumPy multilayer perceptron. It compares A1, B, C1, and C2 across three seeds, tests structural out-of-distribution behavior, candidate conformance, ontology coverage, calibration, and synthetic attacks, and generates all reported numerical artifacts from raw predictions.

\subsection{Contributions}

The contributions are:

\begin{enumerate}[leftmargin=*]
  \item a layered computational model distinguishing canonical axiology, normative authority, domain semantics, purpose relevance, uncertain world state, and extrinsic action assurance;
  \item a reference architecture with separable semantic-to-neural compilation, structural conditioning, normative late binding, and a fixed-verifier boundary;
  \item a falsifiable experimental design with matched model variants, structural-OOD splits, coverage degradation, security fixtures, candidate-action conformance, and seed-level uncertainty;
  \item a runnable research artifact containing ontology fixtures, interface modules, a synthetic pilot, generated tables and figures, tests, and reproducibility records.
\end{enumerate}

\subsection{Scope}

The manuscript evaluates whether explicit semantic structure is a useful inductive bias in a controlled proxy; it does not establish moral truth, legitimate authority, consciousness, machine moral status, formal safety, or a solution to AI alignment.
