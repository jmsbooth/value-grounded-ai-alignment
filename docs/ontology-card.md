# Ontology card: canonical and runtime semantic fixtures

## Canonical source

The governed axiology remains the existing versioned fixture at
`ontology/axiology/core-axiology.ttl`; the empirical data boundary does not
copy that graph. Derived examples record the axiology version and generator
provenance.

## Runtime layers

The pilot separates axiological value/relation features, normative features,
domain/ontology context, purpose, and uncertain world-state qualifiers. The
sealed benchmark applies edge removal, contradictory edges, malicious targeted
changes, and irrelevant edges as synthetic degradation conditions.

## Governance boundary

The learned representation is not authoritative. A content digest, source,
version, and provenance remain external metadata. An unsigned or spoofed
runtime change is an attack fixture, not an authorized axiology transition.

## Limitations

The graph is deliberately bounded and hand-specified. It does not encode a
complete moral theory, resolve pluralistic disagreement, prove legitimacy, or
represent real-world ontology coverage.
