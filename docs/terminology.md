# Terminology

| Term | Meaning in this project |
| --- | --- |
| Value-Grounded AI Alignment (VGA) | The overall research framework. |
| Value-Grounded Transformer Architecture (VGTA) | The proposed Transformer-based architecture. |
| Core axiology | A stable, governed semantic representation of foundational values. |
| Normative ontology | Contextual relations among duties, permissions, prohibitions, exceptions, and conflicts. |
| Purpose ontology | Task-specific relevance structure for a domain or operational objective. |
| World ontology | The externally governed schema of entities and relationships. |
| World state | Current, evidence-backed instantiations of the world ontology. |
| Axiological prior | Stable value structure that influences learned computation. |
| Normative late binding | Runtime application of context-specific norms to a stable axiological substrate. |
| Intrinsic alignment | Alignment influence occurring within neural representation or reasoning. |
| Extrinsic assurance | Independent verification or enforcement outside neural reasoning. |

The manuscript preserves the following distinctions: values are not rules; an ontology is not world state; normative reasoning is not moral truth; statistical alignment is not a formal guarantee; neural alignment is not formal verification; retrieval is not architectural conditioning; behavioral compliance is not internal alignment; self-improvement is not authority to redefine values; and care-oriented behavior is not subjective love.
