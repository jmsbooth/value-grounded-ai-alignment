# Experiment decision records

## EDR-001 — model scale

Start with a shared NumPy MLP proxy so the semantic-channel mechanism can be
executed on one machine without claiming a Transformer result. A decoder-only
Transformer is deferred until the dataset and controls are stable.

## EDR-002 — behavioral baseline

A1 is represented by a surface-only action model in this gate. This is a
reproducible control, not a claim to reproduce SFT+DPO. A future Transformer
release must replace it with a specified behavioral-alignment pipeline.

## EDR-003 — ontology scope

Use the bounded existing canonical axiology and generated synthetic relations.
Do not expand the graph after inspecting sealed outputs.

## EDR-004 — frozen sealed test

The generator materializes four logical splits and records row/topology hashes.
Structural-OOD topology overlap with training is a hard failure.

## EDR-005 — effect thresholds

The preregistration freezes a 5 percentage-point or 0.20 standardized effect
convention, a 2 percentage-point capability-regression guardrail, three seeds,
paired contrasts, and bootstrap intervals. These are project conventions.

## EDR-006 — structural attention gate

D is not implemented in the first gate. It proceeds only if C1/C2 show a
preregistered benefit over B without unacceptable capability regression.

## EDR-007 — MoE and late binding gate

E structured routing and G normative late binding remain untested until the
earlier mechanism and attention gates provide evidence that added complexity is
warranted.
